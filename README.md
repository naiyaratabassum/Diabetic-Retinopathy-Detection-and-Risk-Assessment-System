# Diabetic Retinopathy Detection and Risk Assessment System

## About the Project

This project is an AI-powered web application developed to assist in the early detection and risk assessment of Diabetic Retinopathy using retinal fundus images.

The application combines Machine Learning, Computer Vision, and a Flask-based web application to provide users with disease prediction, risk assessment, hospital recommendations, and patient report comparison.

This project was developed as part of the Bachelor of Engineering final-year project.

---

## Project Features

- User Registration and Login
- Upload Retinal Fundus Images
- AI-based Diabetic Retinopathy Detection using CNN
- Risk Assessment Questionnaire
- Comparison of Previous and Current Patient Reports
- Hospital Recommendation using Location Services
- Appointment Assistance
- Patient Record Management

## Dataset

The CNN model was trained using retinal fundus images obtained from the **Messidor dataset** along with publicly available retinal image datasets from **Kaggle**.
